# Unemployment Insurance Contribution Rate Audit

Reduce unemployment tax through benefit-charge review, experience transfers, voluntary contributions, and timely rate protests.

**Primary buyer:** Multi-state employers and payroll teams. **Evidence:** state accounts, payroll, taxable wage bases, experience ratings, benefit charges, acquisitions, layoffs, voluntary contributions, rate notices, protests, and refunds.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- State account registry
- Taxable wage ingestion
- Rate notice extraction
- Benefit charge statement
- Former employee matching
- Ineligible charge detection
- Experience rating calculation
- Successor predecessor transfer
- Joint account analysis
- Voluntary contribution model
- Rate protest deadline
- Protest evidence package
- Amended return workflow
- Refund reconciliation
- State employer analytics
